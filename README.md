# ChemXR Lab — แล็บเคมีเสมือน AR/VR บนเว็บ ⚛

สื่อการเรียนรู้เคมีแบบ **Web AR / VR** (WebXR) สำหรับจำลองการสร้างโมเลกุล:
หยิบธาตุจากตารางธาตุลอยกลางอากาศ แล้วลากอะตอมมาชนกันเพื่อสร้างพันธะ ระบบจะจัดพันธะเดี่ยว/คู่/สาม
จัดรูปร่างโมเลกุลตามทฤษฎี VSEPR และบอกชื่อโมเลกุลให้อัตโนมัติ — ใช้งานผ่านเบราว์เซอร์ ไม่ต้องติดตั้งแอป

## ความสามารถ

| | |
|---|---|
| 🧪 **ตารางธาตุ 3D ครบ 118 ธาตุ** | แตะ/จีบนิ้วที่ธาตุเพื่อสร้างอะตอม (สี CPK, ขนาดตามรัศมีโคเวเลนต์) พร้อมข้อมูลธาตุ: มวลอะตอม, หมู่/คาบ, การจัดอิเล็กตรอน, อิเล็กโทรเนกาติวิตี |
| 🔗 **สร้าง/ตัดพันธะ** | ลากอะตอมเข้าใกล้กัน วงสีเขียวแสดงว่าจะเกิดพันธะ ปล่อยเพื่อเชื่อม • ดึงอะตอมออกจนพันธะเป็น **สีส้ม** แล้วปล่อยเพื่อตัดพันธะ |
| ⚖️ **ตรวจเวเลนซ์** | ป้ายบอก *"แบบจำลองยังไม่สมบูรณ์ · ต้องการพันธะอีก N"* (เช่น HO) จนกว่าโมเลกุลจะครบ |
| 🧠 **จัดพันธะอัตโนมัติ** | O₂ เป็นพันธะคู่, N₂ พันธะสาม, CO₂ เป็น O=C=O, เบนซีนพันธะคู่สลับ รองรับเวเลนซ์ขยาย (SO₂, H₂SO₄, PCl₅, SF₆, XeF₄) |
| 📐 **รูปร่างโมเลกุล VSEPR** | จำลองแรงผลักของคู่อิเล็กตรอน: น้ำงอ ~104.5°, NH₃ พีระมิด, CH₄ ทรงสี่หน้า, CO₂ เส้นตรง, XeF₄ สี่เหลี่ยมแบนราบ • เปิดแสดง **อิเล็กตรอนคู่โดดเดี่ยว** ได้ |
| 🏷️ **จดจำสาร 210+ ชนิด** | โมเลกุล ~140 ชนิด (เช่น น้ำ, กลูโคส/ฟรักโทส, เอทานอล vs ไดเมทิลอีเทอร์, เอสเทอร์, กรดแอมิโน), ไอออน ~50 ชนิด และเกลือ ~20 ชนิด พร้อมคำอธิบาย มวลโมเลกุล ชนิดพันธะ และสภาพขั้ว |
| ⚡ **ประจุ ไอออน และเกลือ** | ปุ่ม **ประจุ +/−** ดึง/เติมอิเล็กตรอน (Na → Na⁺, SO₄ → SO₄²⁻) ระบบจัด **ประจุฟอร์มอล** ให้เอง (O₃, CO, HNO₃, NH₄⁺) • วางไอออนบวก–ลบใกล้กันจะรวมเป็นเกลือ (NH₄⁺ + Cl⁻ → NH₄Cl) • สารไอออนิกแยกไอออนให้ดู (CaCO₃ = Ca²⁺ + CO₃²⁻) • รู้จักอนุมูลอิสระ (NO, NO₂) |
| 🔬 **แก้ความเข้าใจผิดจากงานวิจัย** | พันธะไอออนิกเป็นแรงดึงดูดไฟฟ้า (เส้นประ) + **ดูโครงผลึก** (NaCl 6:6, CsCl 8:8, CaF₂ 8:4) • **พันธะไฮโดรเจน** ระหว่างโมเลกุล (ขีดเหลือง) + ชนิดแรงและจุดเดือด • **สภาพขั้ว** คิดคู่โดดเดี่ยว (O₃ มีขั้ว) • **เรโซแนนซ์** พันธะเท่ากัน ประจุ −⅔ • **พลังงานพันธะ** ตอนเกิด/สลายพันธะ — รายละเอียดใน [`docs/research-gap-analysis.md`](docs/research-gap-analysis.md) |
| 🧬 **ไอโซเมอร์และโครงสร้างจริง** | ป้าย **cis/trans**, คาร์บอนไครัล **R/S (L/D)**, ปุ่มสลับ cis↔trans และสร้างภาพในกระจก • มุมพันธะ**จากการทดลอง**เทียบกับ VSEPR (H₂S 92°, NO₂ 134°, CaF₂ แก๊สงอ) • ดูโครงสร้าง**เพชร แกรไฟต์ SiO₂** และ**ผลึกโลหะ** bcc/fcc/hcp พร้อมทะเลอิเล็กตรอน |
| 🎯 **โหมดภารกิจ** | โจทย์ 28 ข้อ จาก H₂ ถึงไอออนและเกลือ (Na⁺, OH⁻, NH₄⁺, SO₄²⁻, NH₄Cl, กลูโคส) เก็บคะแนนไว้ในเครื่อง |
| ♻️ **ถังรีไซเคิล** | ลากโมเลกุลไปปล่อยเพื่อลบ |
| 🌐 **ไทย / อังกฤษ** | สลับภาษาได้ทั้งหน้าเว็บและในแว่น |

## อุปกรณ์ที่รองรับ

| โหมด | อุปกรณ์ | การควบคุม |
|---|---|---|
| **AR** | Meta Quest 3/3S/Pro (passthrough), Android + Chrome (ARCore) | มือ (จีบนิ้ว), คอนโทรลเลอร์, แตะหน้าจอ |
| **VR** | Meta Quest, แว่น WebXR อื่น ๆ | มือ (hand tracking), คอนโทรลเลอร์ |
| **โหมดกล้อง** | iPhone/iPad และเครื่องที่ไม่มี WebXR | ซ้อนภาพ 3D บนภาพกล้อง + ทัช |
| **3D** | คอมพิวเตอร์/มือถือทุกเครื่อง | เมาส์/ทัช, ลากพื้นที่ว่างเพื่อหมุนมุมมอง |

**ท่าควบคุม**
- จีบนิ้ว / กดทริกเกอร์ / แตะ ที่ธาตุ → สร้างอะตอม (ลากออกมาได้เลย)
- จับอะตอม → ย้ายทั้งโมเลกุล (ใน XR หมุนข้อมือเพื่อหมุนโมเลกุล)
- **สองมือ** จับคนละอะตอมแล้วดึงออก → ตัดพันธะ (บนจอ: กดค้างหรือ Shift+ลาก)
- แตะอะตอมสองครั้ง → แยกอะตอมนั้นออกจากโมเลกุล
- เลือกอะตอมแล้วกด **ประจุ +** / **ประจุ −** → สร้างไอออน (ถ้าโมเลกุลไม่ครบ ป้ายจะบอกว่าควรเป็นประจุเท่าไร)
- แถบ "ย้าย" บนแผง → ย้ายตารางธาตุไปวางตรงไหนก็ได้

## เริ่มใช้งาน

ไม่ต้อง build — เป็นเว็บไฟล์ static ล้วน (three.js ถูกรวมไว้ใน `vendor/` จึงใช้งานออฟไลน์ในห้องเรียนได้)

```bash
npm start          # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
npm test           # ทดสอบตรรกะเคมีและฟิสิกส์ (Node 18+)
npm run audit      # เทียบผลของแบบจำลองกับข้อมูลจริง 62 กรณี
```

> **WebXR ต้องใช้ HTTPS** (ยกเว้น `localhost`) — วิธีที่ง่ายที่สุดคือเผยแพร่ด้วย **GitHub Pages**:
> Settings → Pages → Source: *GitHub Actions* แล้ว merge เข้า `main` (มี workflow ใน `.github/workflows/pages.yml`)
> หรือเลือก *Deploy from a branch* ที่ root ก็ได้ จากนั้นเปิดลิงก์ `https://<user>.github.io/<repo>/` ใน Meta Quest Browser หรือ Chrome บน Android

ทดสอบบนคอมพิวเตอร์โดยไม่มีแว่น: ติดตั้งส่วนขยาย [Immersive Web Emulator](https://chromewebstore.google.com/detail/immersive-web-emulator/cgffilbpcibhmcfbgggfhfolhkfbhmik) ใน Chrome แล้วกด "เข้าสู่ VR"

## โครงสร้างโปรเจกต์

```
index.html            หน้าเว็บ + import map
css/style.css         UI ลอย (ใช้เป็น DOM overlay ใน AR บนมือถือด้วย)
js/
  main.js             ฉาก, โหมด AR/VR/กล้อง/3D, อินพุตทุกชนิด, ลูปหลัก
  elements.js         ข้อมูลธาตุ 118 ธาตุ (ชื่อไทย/อังกฤษ, มวล, EN, สี, เวเลนซ์, การจัดอิเล็กตรอน)
  chemistry.js        กราฟอะตอม–พันธะ, จัดอันดับพันธะ, วิเคราะห์โมเลกุล (VSEPR, ขั้ว)
  molecules.js        ฐานข้อมูลโมเลกุล + สูตร Hill
  physics.js          จัดรูปร่างโมเลกุล (สปริงพันธะ + แรงผลักคู่อิเล็กตรอน)
  interaction.js      จับ/ลาก/สร้างพันธะ/ตัดพันธะ ใช้ร่วมกันทุกอุปกรณ์
  views.js            วาดอะตอม พันธะ ป้ายชื่อ เอฟเฟกต์
  periodicPanel.js    แผงตารางธาตุ 3D
  info.js             การ์ดข้อมูล (HTML และ 3D ในแว่น)
  challenge.js        โหมดภารกิจ
  audio.js, i18n.js, textures.js
tests/                ทดสอบด้วย node:test
vendor/three/         three.js r160 (MIT)
```

### เพิ่มโมเลกุลใหม่
เพิ่มหนึ่งบรรทัดใน `MOLECULES` ของ `js/molecules.js` เช่น

```js
{ f: 'C2H5Cl', th: 'คลอโรอีเทน', en: 'Chloroethane', dTh: 'คำอธิบาย…', dEn: '…' },
```

ถ้าสูตรเดียวกันมีหลายไอโซเมอร์ ให้ใส่ `test: (comp) => …` เพื่อตรวจโครงสร้าง (ดูตัวอย่างเอทานอล/ไดเมทิลอีเทอร์)
ไอออนใส่ `q` เช่น `{ f: 'SO4', q: -2, … }` ส่วนอนุมูลอิสระใส่ `radical: true`

## ข้อจำกัดของแบบจำลอง (สำหรับครู)
แบบจำลองนี้ออกแบบให้เข้าใจง่ายในระดับมัธยม จึงมีการลดรูปบางอย่าง:
- ประจุฟอร์มอลหาด้วยวิธีค้นหาแบบฮิวริสติก (ประจุน้อยที่สุด, ประจุลบอยู่บนอะตอมที่ EN สูง) และใช้ได้ดีกับโมเลกุลขนาดเล็กถึงกลาง
- สารประกอบไอออนิกแสดงเป็นไอออนที่เชื่อมกัน (เส้นสีม่วง) หรือไอออนวางชิดกัน (เส้นประ) ไม่ใช่โครงผลึก
- ยังไม่รองรับสารเชิงซ้อนของโลหะ (เช่น [Cu(NH₃)₄]²⁺) และพันธะแบบ 3 ศูนย์กลาง (เช่น B₂H₆)
- เวเลนซ์ของโลหะทรานซิชันใช้ค่าที่พบบ่อยเท่านั้น
- เรโซแนนซ์ (เช่นเบนซีน) แสดงเป็นโครงสร้างเคคูเลหนึ่งแบบ
